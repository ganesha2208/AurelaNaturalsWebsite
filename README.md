# Aurela Naturals - Premium Skincare Ecommerce Website

A modern, responsive ecommerce website for Aurela Naturals, a premium natural skincare brand.

## Features

- **Modern Design**: Clean, professional design focused on natural skincare
- **Responsive Layout**: Optimized for all devices (mobile, tablet, desktop)
- **Product Categories**: Cleansers, Toners, Serums, Moisturizers, Sunscreens, Masks, Eye Care
- **User Authentication**: Secure login/signup system
- **Shopping Cart**: Full ecommerce functionality
- **Product Reviews**: Customer testimonials and ratings
- **Admin Dashboard**: Product management for administrators
- **Natural Focus**: Emphasizes organic, cruelty-free, sustainable products

## Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS
- **State Management**: Redux Toolkit
- **Authentication**: Firebase
- **Icons**: React Icons
- **Deployment**: Vercel

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start development server:

   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
